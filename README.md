# DreamWorldGenerator

《林栖》是一个使用 Three.js 与 Vite 构建的浏览器 3D 建造小游戏。玩家可以绘制道路和河流、摆放建筑与植物、扩建连续领地，并以第三人称探索自己的世界。

支持江南水乡、欧式村庄和热带海岸场景，包括沿河水巷、围池庭院、水轮磨坊、林缘牧场、海岬灯塔和礁岸潮池。场景可按种子、大小、建筑密度和植物数量生成，生成后仍可自由改建。

创造与冒险模式可随时切换。动物会根据栖地条件来访，观察记录随世界保存。模型包含独立动画，并使用按需加载和远距离更新降频控制开销。移动设备的实际表现取决于硬件和场景复杂度。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。世界自动保存在当前浏览器中，也可通过游戏内的导出、导入功能迁移存档。

## 构建与验证

```sh
node --test test/*.test.js
npm run build
npm run preview
```

构建产物位于 `dist/`。`performance.html` 提供独立的九地块低画质漫步测试。

## 项目内容

- `src/` 包含建造、地形、角色控制、动物行为和界面代码。
- `public/models/` 包含 GLB 模型及实际模型缩略图。
- `public/audio/` 包含背景音乐。
- `scripts/` 包含 Blender 模型生成与音频生成脚本。
- `test/` 包含自动测试和浏览器验证页面。
